<p align="center" ><br><img src="assets/llamfo.jpg" width = 40%></p>


Este repositório foi criado para a documentação da oficina do PSEL LAMFO 2025.

**Tema: Previsão de Vendas e Sazonalidade com Dados Históricos**

## Objetivo
O objetivo desta oficina é introduzir as  técnicas básicas de séries temporais, como média móvel e decomposição aditiva, para analisar a sazonalidade e prever a demanda com base em dados históricos de vendas, além de responder às perguntas propostas e discutir o tema de forma prática e colaborativa.

## Organização do projeto
Esta wiki esta organizada em pastas: 

- [Início](index.md): Informações gerais sobre o projeto e a wiki;
- [Oficina](home.md): Contém como trabalhamos;
- [Apresentações](apresentacoes.md): Contém quem respondeu as perguntas, o vídeo e os slides;
